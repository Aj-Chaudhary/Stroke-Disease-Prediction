# Stroke Disease Prediction

A machine learning project that predicts the likelihood of stroke based on patient health and demographic information.

## Overview

This project uses machine learning classification techniques to analyze patient data and predict whether a patient is likely to have a stroke.

The project is implemented in Python using a Jupyter Notebook and includes data preprocessing, exploratory analysis, model training, and evaluation.

## Dataset

The project uses the **Healthcare Dataset Stroke Data**, which contains patient demographic and health-related attributes.

The dataset includes features such as:

* Gender
* Age
* Hypertension
* Heart disease
* Ever married
* Work type
* Residence type
* Average glucose level
* Body mass index (BMI)
* Smoking status
* Stroke outcome

The target variable is:

* `stroke` — indicates whether a stroke was recorded for the patient.

## Machine Learning Models

The notebook explores classification using:

* Support Vector Machine (SVM)
* Random Forest Classifier

## Technologies Used

* Python
* NumPy
* Pandas

## Project Workflow

The project follows these general steps:

1. Import required libraries
2. Load the dataset
3. Explore the dataset
4. Handle categorical data using label encoding
5. Prepare features and target variables
6. Split the data into training and testing sets
7. Standardize the features
8. Train machine learning classification models
9. Generate predictions
10. Evaluate model performance

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision

* Confusion Matrix

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Stroke-Disease-Prediction.git
cd Stroke-Disease-Prediction
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Usage

Open the Jupyter Notebook:

```bash
jupyter notebook "Stroke Prediction.ipynb"
```

Run the notebook cells sequentially to reproduce the data analysis, model training, and evaluation.
